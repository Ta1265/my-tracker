# BMAD initiatives

Each subfolder here is one initiative's planning documents and stories, written by the
BMAD workflow. Nothing in this directory defines the process.

**The workflow itself lives in `.claude/skills/bmad/`** - a self-contained plugin
holding the six phase agents, the `/bmad:status` and `/bmad:new` skills, and the
process definition in its `README.md`. Copy that one folder into another project to
reuse the workflow there.

Run `/bmad:status` for the current state of every initiative below, and
`/bmad:new <feature>` to start one.
